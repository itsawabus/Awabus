# Voice files (arrival calls)

Audio played to parents when the bus is near home. Put MP3 files here; the
admin site serves them at `https://<admin site>/voice/<file name>`.

Set that full link as `ARKESEL_VOICE_FILE_URL` on the server (Render).

- Use MP3, under about 10 seconds, no spaces in the file name
  (e.g. `bus-near.mp3`).
- Everything in this folder is public. Never put anything private here.
